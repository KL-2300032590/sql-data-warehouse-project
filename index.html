SQL Data Warehouse Project

This project demonstrates the design and implementation of a modern SQL-based Data Warehouse using the Medallion Architecture approach.

The pipeline ingests raw data, transforms it into structured datasets, and prepares optimized tables for analytical workloads and reporting.

View Source Code on GitHub

Architecture Overview

The system follows a Medallion architecture consisting of Bronze, Silver, and Gold layers. Each layer progressively improves data quality and query performance.

Bronze Layer

The Bronze layer stores raw ingested data exactly as received from source systems. This layer acts as the immutable historical record of incoming datasets.

Silver Layer

The Silver layer applies cleaning, normalization, and transformation logic to prepare reliable structured datasets suitable for analytics.

Key Features

  • SQL-based ETL pipelines
  • Medallion architecture (Bronze / Silver / Gold)
  • Dimensional modeling for analytics
  • Optimized queries for reporting workloads
  • Clear data lineage across transformation stages
